📌 安全数值输入与转换工具（C 语言）
🔍 简介
本程序提供了一套健壮、安全、用户友好的数值输入验证与类型转换功能，专为解决 C 语言中常见的输入处理难题而设计。它能：

✅ 安全读取限定范围内的任意实数（支持小数、负数、科学计数法）
✅ 防止非法输入（如字母、符号混入、空输入、无穷大等）
✅ 安全地将浮点数转换为整数，避免溢出和未定义行为
✅ 自动重试机制：输入无效时提示错误并重新输入
适用于教学实验、嵌入式配置、命令行工具等需要高可靠性输入处理的场景。

🧰 核心功能
1. get_double_in_range(double min, double max)
作用：从标准输入读取一个在 [min, max] 范围内的双精度浮点数。

特点：

拒绝 "123abc"、"3.14xyz" 等混合字符串
自动忽略前后空格（如 "  -5.2e3  "）
支持科学计数法（1.23e5、-4.5E-2）
拦截 inf、nan、溢出值
超出范围时提示并重试
2. safe_double_to_int_trunc(double x)
作用：将 double 安全转换为 int，采用向零取整（截断小数部分）。

安全机制：

自动检查是否在 int 表示范围内（[INT_MIN, INT_MAX]）
超出范围时打印错误并退出程序（避免未定义行为）
3. safe_double_to_int_round(double x)（可选）
作用：四舍五入后转为 int，同样包含溢出保护。

🚀 使用示例
场景 1：获取 0~100 的百分比，并取整
C
编辑
double score = get_double_in_range(0.0, 100.0);
int int_score = safe_double_to_int_trunc(score);
printf("最终得分: %d\n", int_score);
场景 2：模拟“输入不多于5位的正整数”（用浮点接口）
C
编辑
double input = get_double_in_range(1.0, 99999.0);
int num = safe_double_to_int_trunc(input); // 安全！因 99999 < INT_MAX
场景 3：获取坐标（-1000.0 ~ 1000.0）
C
编辑
double x = get_double_in_range(-1000.0, 1000.0);
double y = get_double_in_range(-1000.0, 1000.0);
